# RAG 技术与参数高效微调 (PEFT)剖析


## 大模型应用的核心架构约束

1. 有限上下文窗口：模型只能处理固定长度的输入序列，无法一次性摄入完整知识库
2. 静态知识截止：模型知识固化于训练完成时刻，无法获取实时信息与私有领域知识



## RAG 模块化检索流水线

RAG（Retrieval-Augmented Generation（检索增强生成））

常规简单智能体：用户提问 -> LLM -> 回复
基于 RAG 智能体：用户问合一的成绩 -> （意图识别 -> 知识检索 Agentic RAG） ->  LLM -> 回复

1. 企业知识库（excel、word、csv、pdf）
2. 存储知识库（数据源 → 文档加载器 → 标准化Document → 文档切分器 → 嵌入模型 → 向量数据库【内存】）
3. 检索（向量检索、全文检索、混合检索）
4. 给到模型处理
5. 回复

345 总结：用户查询 → 查询嵌入 → 向量检索 → 上下文聚合 → 提示词模板 → 大模型 → 回答
