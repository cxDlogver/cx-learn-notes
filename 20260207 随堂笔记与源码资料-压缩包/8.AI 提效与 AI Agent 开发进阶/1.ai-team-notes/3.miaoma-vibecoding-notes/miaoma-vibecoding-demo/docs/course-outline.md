# 60 分钟课程大纲

## 课程标题

《大厂前端 AI 工程化与组件库基建最佳实践，架构师带你速通 MCP、Skill、Vibecoding 前端神技》

## 目标受众

资深前端工程师、前端架构师、前端技术负责人。

## 课程主线

AI 编程不是单点提效，而是工程化上下文管理问题。前端团队要让 Codex 写出可落地代码，必须把组件库、工具库、设计规范和团队约束沉淀为模型可读取、可调用、可验证的上下文。

## 时间分配

| 时间 | 模块 | 目标 |
| --- | --- | --- |
| 0-5 min | 开场与问题定义 | 建立“AI 工程化上下文”这个核心视角。 |
| 5-15 min | 大厂前端 AI 工程化沉淀 | 解释 Prompt、Skill、MCP、代码上下文、评审验收链路。 |
| 15-25 min | 设计还原重难点 | 讲清视觉 token、组件约束、布局语义和业务组件缺失带来的偏差。 |
| 25-40 min | 最小组件库基建 | 演示 React + TypeScript + tsup 组件库，完成 Button、Input、Card、Modal。 |
| 40-55 min | 自定义组件库 MCP | 演示 MCP 如何向 Codex 暴露组件清单、Props、示例和使用约束。 |
| 55-60 min | 总结与 Q&A | 回到团队落地：资产标准化、上下文接口化、验收自动化。 |

## 讲完后听众应获得

- 能区分 Prompt、Skill、MCP 在前端 AI 工程化中的职责边界。
- 能理解为什么设计还原是前端 AI 落地的高风险点。
- 能用最小成本搭建 React 组件库并提供稳定公共 API。
- 能用 MCP 把私有组件库知识暴露给 Codex。
- 能把课程 Demo 扩展到自己的团队组件库和工具链。
