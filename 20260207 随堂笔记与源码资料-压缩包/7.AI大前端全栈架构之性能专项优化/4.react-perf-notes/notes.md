# React 应用级性能分析与优化

## 性能优化概要

1. 识别性能瓶颈【S（Situation）TAR】
    - 算法，On2 -> Onlogn -> On -> Ologn
    - 内存占用
    - 页面重新渲染频度 rerender
    - 动画是否卡顿掉帧
    - 页面是否会白屏
    - 首屏加载时间过长
2. 设计优化
    - 改良算法
    - 那些操作大量开辟内存空间（监听事件不解绑、计时器不清除、死循环）
    - 状态优化
    - 较少比较长时间的主进程占用
    - 排查 js 执行错误并修复
    - 减小首屏加载资源体积
3. 持续监控
    - 性能、异常与用户行为分析监控平台
