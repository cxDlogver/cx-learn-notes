# 003 Timeline Core Spec

## 目标

- 建立纯 TypeScript 时间线核心，支撑多轨 clip 的移动、裁剪、分割、碰撞检测和吸附。
- 时间线核心必须独立于 Vue、Electron、FFmpeg，便于单元测试和 AI Agent 安全重构。

## 范围

- 范围内：TimelineState、clip 查询、碰撞检测、移动 clip、裁剪 clip、分割 clip、时间吸附。
- 范围外：拖拽 UI、波形渲染、视频预览、导出 Filtergraph。
- 不做事项：不处理转场、不做磁性时间线自动重排、不修改源素材。

## 用户场景

- Given：时间线已有多个轨道和片段。
- When：用户移动、裁剪或分割某个片段。
- Then：系统返回新的不可变时间线状态，并能报告是否与同轨其他片段冲突。

## 非功能要求

- 所有时间单位统一为毫秒。
- 算法函数必须是纯函数，不读写文件和全局状态。
- 输入非法时返回明确错误，不静默修改状态。
