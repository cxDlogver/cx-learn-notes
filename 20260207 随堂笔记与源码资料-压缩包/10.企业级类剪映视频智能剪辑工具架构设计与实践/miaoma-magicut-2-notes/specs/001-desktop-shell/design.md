# 001 Desktop Shell Design

## 布局

- 顶部：项目标题、保存状态、导出按钮。
- 左侧：脚本总览与素材库入口。
- 中间：视频预览画布与播放控制。
- 右侧：AI 创作、素材替换、字幕、音乐、属性。
- 底部：多轨时间线占位。

## shadcn-vue 组件

- Button、Tabs、Scroll Area、Separator、Badge、Tooltip、Slider、Progress。
- 图标使用 lucide-vue-next。

## 视觉验收

- 暗色背景不使用大面积单一纯黑。
- 控件不重叠，底部时间线固定高度。
- 图标按钮具备可访问标题。
