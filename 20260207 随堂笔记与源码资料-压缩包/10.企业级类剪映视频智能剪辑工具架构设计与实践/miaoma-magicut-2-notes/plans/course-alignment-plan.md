# AI 大前端全栈架构师类剪映智能剪辑工具课程规划

## 1. 课程定位

本课程以 `miaoma-magicut` 为项目载体，围绕“企业级类剪映视频智能剪辑工具”完成一次从需求分析、架构设计、核心编码、AI 自动剪辑到桌面端交付的完整实战。

课程主线不是单纯实现一个 Demo，而是把 Electron、Vue3、FFmpeg、LangChain.js、Whisper、IndexTTS2 与 Vibe Coding 工程工作流串成一个可演进的桌面端音视频产品。

最终项目目标：

- 实现本地多轨视频剪辑器，支持素材管理、时间线、实时预览、字幕、配音和导出。
- 构建本地 AI 创作链路，支持脚本分段、ASR 字幕、TTS 配音、素材推荐和自动组轨。
- 建立企业级工程边界，覆盖 IPC 安全、渲染任务队列、插件化资源管理、跨平台打包和增量更新。

## 2. 与产品方案的对齐

已保存的产品架构方案位于 `plans/video-editor-ai-architecture-plan.md`。课程规划在此基础上增加“教学递进”和“工程讲解”两个维度。

产品 MVP 优先级：

- Electron + Vue3 桌面编辑器。
- 本地素材导入、ffprobe 分析、缩略图、波形、代理文件。
- 多轨时间线，覆盖视频、音频、图片、字幕、配音。
- 视频预览、裁剪、分割、拖拽、吸附、撤销重做。
- FFmpeg 基础导出，默认 H.264 + AAC MP4。
- Whisper 本地转写生成字幕轨。
- IndexTTS2 本地生成配音轨。
- AI 脚本分段，并将字幕、配音、素材片段回填到可编辑时间线。

课程进阶能力：

- Vibe Coding 任务拆解、提示词设计、AI Agent 辅助开发和代码评审。
- LangChain.js 智能剪辑编排层。
- Scene Detection、高光片段识别、语义素材检索。
- BGM 节奏点分析与自动卡点。
- FFmpeg Filtergraph DSL 与滤镜插件系统。
- 分段并行渲染、硬件加速编码、失败恢复。
- Electron 打包、签名、公证、自动更新。

第一阶段不纳入：

- 多人协作。
- 云端素材市场。
- 商业账号系统。
- 完整 AI 生视频平台。
- 高级专业调色与复杂特效系统。

## 3. 学员收益

完成课程后，学员应具备以下能力：

- 能独立拆解复杂音视频产品，设计“多轨编辑器 + 渲染引擎 + AI 决策层”的桌面端架构。
- 能使用 Electron + Vue3 实现复杂交互 UI，包括素材库、时间线、预览区、AI 面板和导出面板。
- 能理解并实践 FFmpeg、ffprobe、Filtergraph、字幕、音频混音、视频叠加和转码导出。
- 能将 Whisper、IndexTTS2、LangChain.js 接入到真实剪辑器，而不是只做孤立 AI Demo。
- 能设计跨进程任务队列、进度回调、取消机制、错误码和日志系统。
- 能掌握 Vibe Coding 在复杂工程中的正确用法，包括需求压实、模块拆分、指令级生成、验证闭环和重构节奏。

## 4. 技术架构

建议课程统一采用以下架构口径：

| 层级 | 技术 | 职责 |
| --- | --- | --- |
| Editor UI | Vue3、TypeScript、Pinia、PixiJS、wavesurfer.js | 素材库、预览区、时间线、AI 面板、导出面板 |
| Timeline Core | TypeScript、zod | 轨道、clip、时间换算、裁剪、分割、吸附、撤销重做 |
| Desktop Shell | Electron、preload、typed IPC | 文件访问、进程隔离、任务调度、安全边界 |
| Media Service | FFmpeg、ffprobe、原生二进制 | 媒体分析、缩略图、波形、代理文件、导出 |
| Render Core | Filtergraph DSL、Render Scheduler | 项目文档编译、滤镜链、音视频混合、分段渲染 |
| AI Orchestrator | LangChain.js | 脚本理解、素材匹配、剪辑决策、Self-Reflection |
| AI Sidecar | Python、FastAPI、Whisper、IndexTTS2 | 本地 ASR、TTS、后续 embedding 与视觉模型 |

关键技术结论：

- 桌面端优先使用原生 FFmpeg，FFmpeg.wasm 作为课程中的技术对比，不作为主实现。
- LangChain.js 负责编排 AI 决策，不直接承担底层音视频算法。
- Whisper 与 IndexTTS2 放在 Python sidecar，避免把重模型运行耦合到 Electron 渲染进程。
- Renderer 不直接访问文件系统和 shell，所有能力通过 preload 暴露的 typed IPC 调用。
- 项目文件优先使用 JSON 文档模型，MVP 不引入数据库，后续素材索引再考虑 SQLite 或向量索引。

### 第 1 章：项目定位与 Vibe Coding 工作流

- 建立 Vibe Coding 的工程闭环：需求压实、架构评审、任务卡、代码生成、验证、重构。

实战产出：

- 项目需求文档。
- 架构设计文档。
- MVP 范围与里程碑。
- AI 辅助开发提示词模板。

### 第 2 章：企业级桌面端架构设计

实战产出：

实战产出：

## 6. 推荐里程碑

### M1：工程骨架与媒体基础

- 完成 Electron + Vue3 项目初始化。
- 完成 typed IPC 与基础安全配置。
- 完成素材导入、ffprobe、缩略图、波形。

验收标准：

- 能导入本地视频、音频、图片。
- UI 能展示素材元信息。
- 缓存目录生成对应缩略图和波形数据。

### M2：多轨时间线与预览

- 完成时间线核心模型。
- 完成多轨拖拽、裁剪、分割、吸附。
- 完成基础预览播放。

验收标准：

- 素材可拖入不同轨道。
- clip 可裁剪、分割、移动。
- 播放头与预览画面同步。

### M3：FFmpeg 导出闭环

- 完成项目文档到 Filtergraph 的编译。
- 完成视频、图片、音频、字幕的基础合成。
- 完成导出进度、取消和失败日志。

验收标准：

- 可导出 H.264 + AAC MP4。
- ffprobe 校验分辨率、时长和音频流正确。
- 导出失败时能看到可定位日志。

### M4：本地 AI 字幕与配音

- 接入 Whisper。
- 接入 IndexTTS2。
- 生成字幕轨和配音轨。

验收标准：

- 视频或音频可生成可编辑字幕。
- 脚本可生成 WAV 配音。
- 字幕、配音和时间线片段可对齐。

### M5：AI 自动剪辑与课程完整闭环

- 接入 LangChain.js。
- 实现脚本分镜、素材匹配、自动组轨。
- 初步实现 BGM 节奏吸附。

验收标准：

- 输入脚本后能生成可编辑时间线。
- 用户能手动替换素材并重新导出。
- AI 输出有结构化 JSON 和反思检查报告。

### M6：性能优化与交付

- 实现分段渲染和硬件加速探测。
- 完成插件化 Provider 初版。
- 完成桌面端打包和自动更新配置。

验收标准：

- 大文件导出稳定。
- 硬件加速不可用时可自动 fallback。
- 能生成可安装桌面应用。

## 7. 教学重点与技术口径

- “像素级同步”建议统一表述为“时间戳级或帧级同步”。字幕、TTS、ASR 与画面的关键是时间轴对齐。
- “LangChain.js 实现场景分割”建议表述为“LangChain.js 编排场景分割”。底层场景检测来自 FFmpeg scene score、字幕语义、音频能量或视觉模型。
- “硬解码加速”和“硬件编码加速”需要分开讲。预览更关注解码与缓存，导出更关注编码。
- 桌面端主实现使用原生 FFmpeg；FFmpeg.wasm 适合浏览器端能力对比。
- 内部自用阶段可以研究 GPL/AGPL 项目实现思路，但不复制代码进入项目。

## 9. 风险与控制策略

- 音视频复杂度高：先完成基础剪辑闭环，再逐步叠加高级效果。
- AI 输出不可控：所有 Agent 输出必须是结构化 JSON，并经过 zod 校验。
- 本地模型部署复杂：模型路径、运行环境和依赖安装必须独立配置，不随应用主体强绑定。
- 跨平台 FFmpeg 差异：统一做能力探测和 fallback，不假设所有平台支持同一编码器。
- 时间线状态复杂：Timeline Core 保持纯 TypeScript，避免与 UI 事件和 FFmpeg 命令耦合。
- 性能优化容易过早复杂化：MVP 先实现单任务导出，分段并行渲染放到进阶阶段。

## 10. 推荐课程主线

课程叙事建议固定为三段：

1. 先做一个可用剪辑器：素材、时间线、预览、导出。
2. 再让剪辑器具备 AI 能力：ASR、TTS、脚本分镜、素材匹配、自动组轨。
3. 最后把它变成工程级产品：性能优化、插件化、打包、更新、发布。

这样既能保证项目落地，又能把 Vibe Coding、FFmpeg、LangChain.js、Electron、Vue3 的价值讲清楚。
