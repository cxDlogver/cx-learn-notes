## 业务概述

### 电商内容主张是什么？

- **从品牌视角看**，2025 年抖音电商升级品牌主张为「[总能发现好东西](https://bytedance.larkoffice.com/docx/YtJed0Af9oFqh1xXFfYcNjMLnbe)」，**电商内容**支撑好品牌升级的目标，围绕「真实、丰富、发现」三大用户心智构建**内容生态**。
- **从供给视角看**，电商视频自然流量萎缩，作者规模缩窄，虽然人均投稿还在增长，但新增供给无法撬动自然流量增长，核心原因是**交易型内容增长受限于高营销感，低互动率，无法绕过营销感打压**；同时从[用研](https://bytedance.larkoffice.com/docx/JdTOd6zEEox4UGxdlhhcJ9hQnBb)的结论看，电商内容的用户满意度低于大盘（GAP -14.1%），视频供给结构亟需改变。
- **从竞争视角看**，「**高价值人群**」消费[小红书](https://bytedance.larkoffice.com/docx/Bqz4dVY8FohkyzxLFadcXJCKnkU)种草内容时长超越淘系、抖音，且在近年仍有可观的 GMV 规模，其差异化优势之一就在于**内容主张明确**，满足了用户种草/经验决策的需求；淘宝直播推出**优质的标准**（音画质量、互动内容、有质价比的商品、专业真实的讲解），希望用**品质直播**撬动更多增长。
- **从价值视角看**，短视频价值被低估，视野局限在挂车直接价值上，但短视频还有引流、种草等价值，且占到短视频全域价值的 93.27%。

### 内容运营是什么？

为实现品牌升级、撬动供给增长，改变视频供给结构，单纯依靠生态自我调节或者产品定向扶持牵引效果并不显著，强烈依赖内容运营专家作为内容电商的**核心操盘手调节**内容生态。核心通过明确视频价值刻画，根据内容主张，围绕「真实、丰富、发现」三大用户心智制定标准，通过一系列**工作流**，对电商内容进行规模化**识别**、**牵引**，构建内容生态，支撑好品牌升级目标，提升优质内容供给，**带来电商内容 Load 和 GMV 增长**。

### 目标

> 25 年业务围绕两个核心目标：  
> 1. **提升短视频 load**  
> 2. **调优电商内容结构**

#### 核心思路

- **视频全域价值刻画：**明确短视频三类价值以及归因方式，从“直接成交”升级为“全域增量成交”（包括直接、间接、种草价等），作为调整分发、透传与供给的基调。
- **明确并统一电商视频标准，引导内容供给：**校准并对齐主端内容标准分发策略。抖音营销内容标准下，电商的大部分视频会被判定为“灰度营销”，导致内容队列不分发。由于标准定义过于严格，对电商造成较大误伤，Q3 起以电商内容标准作为参考，对主端营销内容标准进行校准。
- **完善电商内容价值目标：**从内容消费动作和优/劣质内容中寻找有价值的信号加入视频分发机制，改善当前电商视频与内容价值导向的不同向问题，牵引供给生态改善的同时提升收益天花板。
- **创作牵引：**提供「热点运营产品」能力，提升运营分发-达人造热能力，并进行热点数据分析，提升运营工作效率。

> 基于上述背景、目标以及核心思路，**运营平台团队**希望**搭建**并**完善**内容运营基建能力，让运营看清供给现状，对内容做好分级，并能够及时对分级结果进行干预和纠偏。同时，能够通过热点等**运营工具**牵引投稿。

### 关键动作：完善内容运营基建能力

**运营基建建设：**视频管理、内容评级机审-修正-人审链路、热点运营工作流建设。

- **视频管理：**让运营看清楚平台供给现状以及数据表现，及时对分级结果进行干预以及纠偏。

> 具体信息：透传视频基础数据、主端处罚治理信息、**全域价值刻画数据**（直接、间接数据，种草数据等），并提供内容评级申诉/修改操作。

- **内容评级机审-修正-人审链路搭建：**通过优化流量机制、作者牵引建立一套优质导向的系统机制，引导提升优质视频规模，改善用户平台电商心智，进而拿到生态价值和电商交易价值。

> 具体工作流：制定优质标准 -> 内容评级 -> 内容打标 -> 策略应用（流量分发、分成优质倾斜）-> 透传牵引 -> 价值论证。

- **热点运营：提升热点运营工具，牵引高等级达人参与热点投稿。**

> 让运营以全局视角看到所有热点，并根据热点与达人的匹配度，批量定向达人触达并牵引投稿，提升工作效率以及触达人群数量，从而提升投稿量级。

### 名词解释

| 分类 | 概念 | 定义 |
| --- | --- | --- |
| 视频价值刻画 | 视频价值 | 将视频价值分为三类（直接 GMV、间接 GMV、种草 GMV），统称为**全域增量成交**，并通过埋点 + 长效归因。 |
| 视频价值刻画 | 直接 GMV | 用户看了挂 A 商品的视频，直接通过视频挂载的商品链接购买了 A 商品。 |
| 视频价值刻画 | 间接 GMV | 用户看了 A 视频后一段时间后，通过搜索/商城/橱窗/店铺等渠道，购买了 A 作者/A 店铺产生的 GMV。 |
| 视频价值刻画 | 种草 GMV | 用户看了 A 视频后一段时间后，购买了 B 作者/B 店铺产生的 GMV，A 和 B 有相关性。 |
| 内容评级 | 评级分级与标准 | [电商内容运营 One Page（25 年）](https://bytedance.larkoffice.com/docx/CwM6dMRkao7fIfx7uzcce1dTnXb)；[电商视频-挂车-分级标准 V2.0【对内版】](https://bytedance.larkoffice.com/docx/BEI9dInWDodzYyxTw0CcsKASnjd)。整体评级：优质-标杆、优质-良好、普通、劣质。分维度评级：内容信息量、人格化、画风挺干、商品心智价值。 |
| 内容评级 | 原始机审结果 | 图谱在劣质模型识别基础上，根据**优质标准**构建优质识别模型。评级结果包括优质、普通、无评级、劣质，日均审出量级 279w+，优质 14w+。 |
| 内容评级 | 修正机审结果 | 图谱优质识别模型评级后，服务端再根据**主端**原创识别模型、同质化识别模型等结果进行降级修正。日均修正量级 60w，其中对优质修正量级 1w，占优质量级的 25%。**优质/普通**根据条件修正为「劣质」「无评级」「普通」。 |
| 内容评级 | TCS | CQC 人审平台，审核信息送到平台指定队列，CQC 同学进行审核。 |
| 内容评级 | CQC 人审结果 | CQC 在 TCS 众包任务平台对送审稿件进行审核打标，增加评级结果置信度。评审结果为优质-标杆、优质-良好、普通、无评级、劣质。 |
| 内容评级 | 内容运营人审结果 | 电商内容运营对内容的人工评级，运营核查，最高等级审核结果。 |
| 热点运营 | 策划话题和热点话题 | **话题**分为热点话题和策划话题。策划话题是运营策划好热点词并在固定时间上线的话题；热点话题是热点事件由用户自发投稿讨论跑出来的话题。 |
| 热点运营 | 话题活动 | **话题活动**是基于策划话题发起的活动。为提高策划话题热度，使其能够变成热点上榜，运营会发起造热活动，通过提供平台投流权益吸引高粉作者参与策划话题投稿（非挂车视频）。 |

- **平台透传：**优质透传、非优外化、劣质诊断、数据集展示、运营后台展示等。

#### 内容评级详细流程

##### 标准定义

![内容评级标准维度](assets/内容运营OnePage_assets__image-20-rating-dimensions.png)

- **1.0 标准，3 行业：**[电商内容-视频-分级标准](https://bytedance.larkoffice.com/docx/YzQXdk5LjoniLyxT0y3ceWxOnFf) + 送人审策略。

  - 劣质模型准确率/召回率：83%/89%；覆盖全行业。
