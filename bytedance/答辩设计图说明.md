# 实习生转正答辩设计图草稿

答辩独立设计图统一存放在 `assets/`，当前未写入 `实习生转正答辩.md`。每张图保留 SVG 源文件，便于继续修改文字、配色和布局；PNG 文件用于预览和后续插入文档。

## 设计图清单

1. `01-双轨工作里程碑`
   - 图形类型：双轨时间轴
   - 表达重点：业务交付与 AI 能力沉淀如何相互推动
   - 建议位置：第二章“工作成果全景”之后

2. `02-四种权限状态机`
   - 图形类型：状态机
   - 表达重点：四种权限状态、状态变化条件和前后端职责边界
   - 建议位置：3.1.2 技术评审或 3.1.3 前端实现思路

3. `03-AI-Coding工作流能力分层`
   - 图形类型：能力分层图
   - 表达重点：需求、约束、执行、验证、闭环五层能力，以及 Gate、BITS 和人工审查的横向作用
   - 建议位置：第四章 AI Coding 技术贡献

4. `04-未来能力路线图`
   - 图形类型：阶段路线图
   - 表达重点：从前端需求主责到全栈研发，再到 Agent 应用开发的能力扩展
   - 建议位置：第五章自我复盘与后续规划

## 使用说明

- 当前图稿尺寸均为 1600 × 900，适合答辩投屏和文档横向展示。
- 正文确认前，建议重点校对时间节点、阶段名称和能力检验口径。
- 后续如写入文档，优先使用 PNG；需要调整内容时编辑对应 SVG。
