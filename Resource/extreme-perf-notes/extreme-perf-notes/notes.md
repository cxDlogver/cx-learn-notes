# 极端性能优化实战

## 业务梳理以及度量

- 高频交互
  - 在线协同白板
  - 在线协同编辑器
  - 在线实时 K 线图
  - 高频拖拽与缩放
- 巨量数据
  - 列表 -> 千行以上
  - 日志分析平台（大流量 -> 流量削峰【消息队列】）
  - 模型训练数据
- 计算密集型
  - 端侧音视频编解码
  - 复杂加解密
  - 3D 素材或者是模型加载【OBJ/STL/glTF】，cesium 3dTiles

## 虚拟列表与虚拟滚动原理详解

虚拟列表、虚拟表格

- 传统 DOM 不做优化是什么样子（几百个 dom 时候就非常卡顿了）
- 通过虚拟化【可视区渲染】技术来实现
- 千万行甚至是上亿行数据的列表、表格渲染，canvas 技术来绘制（canvas 绘制性能瓶颈只取决于你的绘制算法）
- canvas table tile rendering
- 基于 rust + wasm 优化，（因为前端 canvas 其实底层是 skia 引擎）

## 千万行数据表格渲染优化方案

- 基于 canvas 实现基础功能绘制（表头、单元格、编辑）
- 联动滚动，计算当前视窗数据
- 动态渲染

## Webassembly (WASM) 基础进阶与实战

语言选择：rust
打包：wasm-pack

开发步骤

1. 使用 rust 来开发端侧功能（图片压缩、灰度处理，音视频裁剪）
2. 使用 wasm-pack 打包代码生成 wasm
3. 前端通过胶水层代码接入，并执行
