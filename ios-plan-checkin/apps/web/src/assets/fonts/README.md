# Noto Sans SC

Web 自托管字体；不依赖用户设备的系统字体或外部字体服务。

- 上游：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc)
- 来源版本：`a85815a42757630ce188fdad368c2dfc444d4773`
- 原文件：`NotoSansSC[wght].ttf`；使用 fontTools 4.25 转为完整可变 WOFF2，未裁剪字符。
- `NotoSansSC.woff2`：7,787,512 字节；SHA-256 `1189a8d6235d662b124d0c37136a9f19f1b5298de294123e596a375102beb0e3`。
- 许可：随目录的 `OFL.txt`（SIL Open Font License 1.1）。
- 使用 `font-display: swap`；截图检查须等待 `document.fonts.ready`。首次下载期间可短暂显示备用字体。
