# APP-07 主流程页面状态清单

> 开发阶段状态盘点；正式 ATDD 验收仍以独立验收矩阵执行。视觉基线是 Pen 节点树与页面图，色彩语义和无障碍说明参照 UI/UX 文档。这里记录代码入口及尚待原生环境验证的状态，不把静态检查写成真机验收。

## 共用规则

| 场景 | 实现规则 | 代码入口 |
| --- | --- | --- |
| 数据加载 | 明确显示加载文案和活动指示器；页面中的旧数据可保留，不把空数据误判为加载完成 | `ScreenState(kind="loading")` |
| 读取失败 | 告知失败并提供至少 44pt 的重试触控区域；失败文案可由 VoiceOver 读出 | `ScreenState(kind="error")` |
| 空态 | 描述为何当前无内容，并给出可执行下一步；无内容的日期不伪装成失败 | 各页业务空态 |
| 本机缓存 | 写明显示来源；本机待同步记录与统计截止日分开说明 | `StatusNotice(kind="offline"/"pending")` |
| 写入失败 | 保留表单内容和选择，显示明确错误，不在错误后自动离开 | `ErrorText` / `InlineError` |
| 系统权限关闭 | 保留核心记录能力，明确当前受限能力与设置入口；照片和通知接入时复用通知组件 | `StatusNotice(kind="permission")`；实际权限入口归 SYNC-04/SOC-04 |
| 屏幕阅读与动态字体 | 结果始终带文字；操作有名称、忙碌/禁用状态，文本允许系统字体缩放，内容可滚动 | `Choice`、`Submit`、`PrimaryAction`、页面 `Pressable` |

## 静态阶段退出检查

1. `pnpm check`：格式、ESLint、TypeScript strict、Pen 映射、配置与安全静态扫描。
2. `pnpm mobile:bundle:check`：iOS JavaScript 静态导出。
3. 开发自检：`mobile:architecture:smoke`、`mobile:plans:smoke`、`mobile:plan-repository:smoke`、`mobile:records:smoke`、`mobile:calendar:smoke`。
4. 真实 VoiceOver、字体放大、iOS 系统权限与 393×852 视觉对齐，保留在任务台账的原生环境阻断项中，不在本阶段判定通过。
