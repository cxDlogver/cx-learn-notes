# Web 样式与移动端结构对齐

## 1. 本次已确认的规则

- 视觉权威：当前 [Pen](./plan-checkin.pen) 与结构化节点；字体采用 Noto Sans SC。
- 所有屏幕采用 `min(100%, 480px)` 单列容器，水平居中、顶部排布；外侧填主题背景。字号、图标和控件不整体缩放。允许纵向滚动，禁止横向溢出。
- 四项底部主入口：今日、日历、计划、朋友。详情、计划创建/编辑、分组、设置详情使用独立页面；消息、设置从页内进入。
- 有画板的页面对齐结构、字体、颜色、尺寸、字重、文案与状态；无画板页面保留既有内容，使用同一外壳和公共样式。
- 浅/深色结构和尺寸相同；深色使用语义配色。取消逐像素阈值。动态内容取真实数据，业务冲突按 Web PRD。

修改来源后先同步视觉树与映射，执行 `pnpm design:build`；`pnpm design:check` 会拒绝来源摘要或生成文件漂移。生成文件不手工维护。截图检查等待 `document.fonts.ready`，记录实际字体加载状态。

## 3. 页面改造与业务差异

| 范围 | 实际实现 | 保留的业务规则 |
| --- | --- | --- |
| 登录/验证码/资料 | 品牌图标、单列手机号、协议提示、六格验证码、资料标题和头像占位 | 本地短信桩提示、撤销注销入口、真实用户名/昵称校验；验证码不写入证据 |
| 今日 | 日期/时区/页内消息与设置，待处理/本周可记录/截止事项/已记录分区，卡片结果按钮 | 卡片状态源于API；编辑开启期间固定所在分区，保存后保留照片绑定重试与冲突状态，关闭才重新分区 |
| 计划 | 进行中/暂停/归档分段、分组列表、创建类型选择、独立分组/编辑/分享页面 | 种类/方向/时区/开始日期的不可变约束保留；新增分组字段使用现有接口 |
| 详情/统计/记录 | 标题与徽标、统计优先、历史/一次性结果、折叠规则、移动式记录弹层 | 幂等、修正、补记、照片/数值、反向状态与权限不变；统计仍以API为准 |
| 日历 | 月切换、七列星期/日期、状态符号、今日入口 | 业务时区和日期保持原语义；日详情无独立画板，保留现有内容 |
| 好友/分享 | 好友列表及申请，好友头像与共享列表，只读详情，权限→选择→预览阶段 | 不伪造好友分享数；预览使用服务端裁剪内容，不分享私人统计、照片和数值 |
| 设置/提醒/数据 | 设置行与独立通知/导出/注销页；接入三类计划的真实提醒规则编辑 | 规则共享、投递分端；浏览器能力与授权反馈保留。注销为30天可撤销；导出仍为固定全量ZIP |

原生系统状态栏、数字键盘、离线同步不迁移；没有已实现业务的画板入口不创建空链接。消息中心、换号、浏览器能力、注销等待状态均继承公共样式，不新增专用设计。
