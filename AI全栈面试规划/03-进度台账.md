## 2. 仓库基线判断

### 【已有沉淀】

AI 目录已经存在企业 Agent 知识框架、五层架构教程、最小 Agent 代码以及 LangChain/LangGraph/Deep Agents 教程；前端和项目目录存在清华走航车、官网、性能、监控、工程化及面试回答资料。这些材料说明相关主题已经学习和沉淀，但当前没有统一的脱稿、运行和追问证据，因此初始状态记为 S1。

### 【明显缺口】

`后端学习/` 目前主要是数据库简表和 Django 入门，尚未形成与 Agent Runtime 对齐的 Node.js/NestJS、PostgreSQL 事务与并发、Redis/BullMQ、幂等、鉴权、安全、可观测性和部署体系。

现有最小 Agent 明确没有数据库 Checkpoint、向量检索、真实 HITL、幂等副作用和沙箱；LangGraph 教程虽有对应框架示例，但还没有把这些机制贯穿为可面试演示的个人知识库 Agent。
