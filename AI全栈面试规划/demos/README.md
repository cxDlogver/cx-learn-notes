# Demo 工作区

## 1. 目录约定

后续代码统一放在本目录：`knowledge-agent/` 保存持续演进的个人知识库 Agent；`micro/主题名/` 保存由复习缺口触发的微型 Demo。

## 2. 创建门禁

创建代码前先在 [Demo 组合规范](../05-Demo组合规范.md) 中确认对应能力切片，并在 [进度台账](../03-进度台账.md) 中登记完成证据。主 Demo 不以一次性生成完整项目为目标，按最小垂直链路逐步增加可验证能力。

微型 Demo 必须有 README、运行命令和失败断言；达到目标后记录是否合并主 Demo，避免只留下无法复现的代码片段。
