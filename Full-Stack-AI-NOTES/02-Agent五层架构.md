# 02 Agent 五层架构

> 本章正文已整合进 [Agent 完整学习教程](./Agent学习教程.md) 第 7 章。

> 当前文件作为兼容入口保留，避免历史链接失效；后续不再重复维护完整五层定义。

五层职责继续统一为：

~~~text
Model
Context
Execution
Orchestration
Feedback & Control
~~~

五层描述的是 **职责架构**，不是一次运行的线性顺序；Agent Loop、Runtime、Harness 是另一组运行和装配视角。完整关系、编排三维模型以及与最小实现的对应关系统一在 [Agent 完整学习教程](./Agent学习教程.md) 中维护。
