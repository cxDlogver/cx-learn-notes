# JS正则表达式核心笔记

# 正则表达式基础认知

## 什么是正则表达式

正则表达式（Regular Expression），简称正则，是一种用于匹配、查找、替换和提取字符串的规则工具，本质是一套定义好的字符匹配模式，可快速处理文本内容。

## 常见用途

- 表单校验：验证手机号、邮箱、验证码等格式是否合法。

- 字符串查找：在一段文本中找到符合规则的内容（如找出所有数字）。

- 字符串替换：替换敏感词、多余字符，或格式化文本（如替换空格）。

- 提取特定内容：从字符串中提取需要的信息（如提取URL参数、日期中的年份）。

- 批量处理文本：高效处理大量文本，减少重复操作。

## 示例场景

- 判断一个字符串是否为中国大陆手机号。

- 从URL中提取指定参数（如从`https://test.com?id=123&name=tom`中提取id的值）。

- 替换字符串中的多余空格，或将多个空格压缩为一个。

- 从一段文本中提取所有数字、邮箱或日期。

# JS中创建正则表达式的方式

JS中创建正则表达式有两种核心方式，根据使用场景选择合适的写法：

## 字面量写法（最常用）

语法：直接用`/正则规则/修饰符`，适用于正则规则固定、无需动态拼接的场景。

```javascript
// 基础字面量写法，匹配字符串中的"abc"
const reg = /abc/;
// 带修饰符的字面量写法，忽略大小写匹配"abc"
const regWithFlag = /abc/i;
```

## 构造函数写法

语法：`new RegExp("正则规则", "修饰符")`，适用于正则规则需要动态拼接（如根据变量生成规则）的场景。

```javascript
// 基础构造函数写法
const reg = new RegExp("abc");
// 动态拼接正则规则示例
const keyword = "hello";
// 动态生成正则，忽略大小写匹配keyword的值
const reg = new RegExp(keyword, "i");
```

# 最常用的正则匹配方法

正则表达式的匹配方法分为两类：正则对象的方法、字符串的方法，核心常用方法共6种，分别对应不同使用场景：

## 1. 正则对象的test()方法

核心作用：判断字符串是否匹配正则规则，返回值为布尔值（`true`匹配成功，`false`匹配失败）。

```javascript
const reg = /abc/;
// 匹配成功，返回true
console.log(reg.test("123abc456")); // true
// 匹配失败，返回false
console.log(reg.test("123456")); // false
```

### 适用场景

- 表单校验（如验证手机号、邮箱格式）。

- 判断字符串中是否包含某种特定格式的内容。

## 2. 正则对象的exec()方法

核心作用：获取字符串中匹配正则的详细信息，返回值为数组（匹配成功）或`null`（匹配失败）。

返回数组的结构：`[匹配内容, index: 匹配起始位置, input: 原始字符串]`（若有捕获组，会在数组中新增捕获组内容）。

```javascript
const reg = /abc/;
// 匹配成功，返回包含匹配详情的数组
console.log(reg.exec("123abc456")); 
// 结果：["abc", index: 3, input: "123abc456"]
```

### 适用场景

- 需要获取匹配到的具体内容。

- 需要获取匹配内容在原始字符串中的起始位置（index）。

## 3. 字符串的match()方法

核心作用：从字符串中提取匹配正则的内容，返回值为数组（匹配成功）或`null`（匹配失败）。

注意：不带修饰符`g`时，返回第一个匹配项及详情；带`g`时，返回所有匹配项组成的数组。

```javascript
const str = "abc123def456";
// 不带g，返回第一个匹配的数字及详情
console.log(str.match(/\d+/)); // ["123", index: 3, input: "abc123def456"]
// 带g，返回所有匹配的数字组成的数组
console.log(str.match(/\d+/g)); // ["123", "456"]
```

### 适用场景

从字符串中提取一个或多个匹配项（如提取所有数字、所有邮箱）。

## 4. 字符串的replace()方法

核心作用：根据正则规则替换字符串中的匹配内容，返回替换后的新字符串（不修改原始字符串）。

```javascript
const str = "hello 123 world 456";
// 全局替换所有数字为"*"
const result = str.replace(/\d+/g, "*");
console.log(result); // hello * world *
```

### 适用场景

- 替换敏感词（如将脏话替换为星号）。

- 替换多余字符（如替换多余空格、换行符）。

- 格式化文本（如将日期格式从“2026-03-15”替换为“03/15/2026”）。

## 5. 字符串的search()方法

核心作用：查找字符串中第一个匹配正则的位置，返回值为匹配起始索引（匹配成功）或`-1`（匹配失败）。

```javascript
const str = "hello123";
// 查找第一个数字的位置，返回5（索引从0开始）
console.log(str.search(/\d/)); // 5
```

### 适用场景

快速获取字符串中第一个匹配内容的位置，无需获取匹配详情。

## 6. 字符串的split()方法

核心作用：根据正则规则分割字符串，返回分割后的数组。

```javascript
const str = "a,b;c|d";
// 按逗号、分号、竖线分割字符串
console.log(str.split(/[,;|]/)); // ["a", "b", "c", "d"]
```

### 适用场景

按复杂规则分割字符串（如多分隔符分割），替代传统的固定分隔符分割。

# 正则核心语法

## 常见元字符

元字符是正则表达式中具有特殊含义的字符，用于定义匹配规则，核心常用元字符如下（按使用频率排序）：

### 1. . （点）

含义：匹配任意单个字符（默认情况下，不能匹配换行符`\n`）。

```javascript
const reg = /a.c/;
// 可匹配：abc、a1c、a-c、a@c
// 不可匹配：ac（缺少中间字符）、a\nc（换行符）
```

### 2. \d

含义：匹配任意一个数字，等价于`[0-9]`。

```javascript
const reg = /\d/;
// 可匹配：0-9任意一个数字
// 不可匹配：字母、符号、空格
```

### 3. \D

含义：匹配任意一个非数字字符，等价于`[^0-9]`。

```javascript
const reg = /\D/;
// 可匹配：字母、符号、空格
// 不可匹配：0-9任意一个数字
```

### 4. \w

含义：匹配任意一个字母、数字或下划线，等价于`[A-Za-z0-9_]`。

```javascript
const reg = /\w/;
// 可匹配：a-z、A-Z、0-9、_
// 不可匹配：@、#、空格等特殊字符
```

### 5. \W

含义：匹配任意一个非字母、非数字、非下划线的字符，与`\w`相反。

### 6. \s

含义：匹配任意一个空白字符，包括空格、制表符（`\t`）、换行符（`\n`）等。

```javascript
const reg = /\s/;
// 可匹配：空格、\t、\n
// 不可匹配：字母、数字、符号
```

### 7. \S

含义：匹配任意一个非空白字符，与`\s`相反。

### 8. \b

含义：匹配单词边界（单词与非单词字符的交界处），用于匹配完整单词。

```javascript
const reg = /\bcat\b/;
// 可匹配：cat（完整单词）、a cat（cat前后是非单词字符）
// 不可匹配：category（cat是单词的一部分，无边界）
```

### 9. ^ （脱字符）

含义：匹配字符串的开头（若带`m`修饰符，匹配每一行的开头）。

```javascript
const reg = /^abc/;
// 可匹配：abc123、abcdef
// 不可匹配：123abc、aabc
```

### 10. $ （美元符号）

含义：匹配字符串的结尾（若带`m`修饰符，匹配每一行的结尾）。

```javascript
const reg = /abc$/;
// 可匹配：123abc、defabc
// 不可匹配：abc123、abcc
```

## 字符集写法

字符集用于定义“匹配一组字符中的任意一个”，核心写法有3种，灵活用于匹配特定范围的字符：

### 1. [abc] （基础字符集）

含义：匹配括号内的任意一个字符（a、b、c中的任意一个），只匹配单个字符。

```javascript
const reg = /[abc]/;
// 可匹配：a、b、c
// 不可匹配：d、ab、1等
```

### 2. [^abc] （否定字符集）

含义：匹配除了括号内字符（a、b、c）之外的任意一个字符，^在字符集内表示“否定”。

```javascript
const reg = /[^abc]/;
// 可匹配：d、1、@、空格等
// 不可匹配：a、b、c
```

### 3. 范围写法（常用）

含义：用`-`连接字符，定义字符范围，匹配范围内的任意一个字符，常用范围如下：

```javascript
// 匹配任意一个小写字母（a-z）
const reg1 = /[a-z]/;
// 匹配任意一个大写字母（A-Z）
const reg2 = /[A-Z]/;
// 匹配任意一个数字（0-9）
const reg3 = /[0-9]/;
// 匹配任意一个字母或数字（a-z、A-Z、0-9）
const reg4 = /[a-zA-Z0-9]/;
```

## 量词：控制匹配次数

量词用于控制前面的元字符或字符集的匹配次数，是正则中非常重要的部分，核心常用量词共6种：

### 1. * （星号）

含义：匹配前面的字符0次或多次（可匹配0次，即不出现）。

```javascript
const reg = /ab*c/;
// 可匹配：ac（b出现0次）、abc（b出现1次）、abbc（b出现2次）、abbbc（b出现3次）
```

### 2. + （加号）

含义：匹配前面的字符1次或多次（至少出现1次，不能匹配0次）。

```javascript
const reg = /ab+c/;
// 可匹配：abc（b出现1次）、abbc（b出现2次）
// 不可匹配：ac（b出现0次）
```

### 3. ? （问号）

含义：匹配前面的字符0次或1次（最多出现1次）。

```javascript
const reg = /ab?c/;
// 可匹配：ac（b出现0次）、abc（b出现1次）
// 不可匹配：abbc（b出现2次）
```

### 4. {n} （固定次数）

含义：匹配前面的字符恰好n次（n为非负整数）。

```javascript
// 匹配恰好6位数字
const reg = /\d{6}/;
// 可匹配：123456、654321
// 不可匹配：12345（5位）、1234567（7位）
```

### 5. {n,} （至少n次）

含义：匹配前面的字符至少n次（n为非负整数，可无限次）。

```javascript
// 匹配至少2位数字
const reg = /\d{2,}/;
// 可匹配：12（2位）、123（3位）、123456（6位）
// 不可匹配：1（1位）
```

### 6. {n,m} （n到m次）

含义：匹配前面的字符n次到m次（n≤m，均为非负整数）。

```javascript
// 匹配2到4位数字
const reg = /\d{2,4}/;
// 可匹配：12（2位）、123（3位）、1234（4位）
// 不可匹配：1（1位）、12345（5位）
```

## 分组与或

分组和“或”用于组合多个字符或规则，实现更复杂的匹配，核心用法有3种：

### 1. () （分组）

含义：将括号内的内容视为一个整体（分组），可配合量词控制整个分组的匹配次数。

```javascript
// 匹配"abc"整体1次或多次
const reg = /(abc)+/;
// 可匹配：abc（1次）、abcabc（2次）、abcabcabc（3次）
```

### 2. | （或）

含义：匹配“|”左边或右边的规则，相当于“二选一”（可多个|连用，实现多选一）。

```javascript
// 匹配"apple"或"banana"
const reg = /apple|banana/;
// 可匹配：apple、banana
// 不可匹配：orange、app
```

### 3. 分组配合量词

含义：将分组与量词结合，控制分组整体的匹配次数，是最常用的组合用法。

```javascript
// 匹配"ab"整体2次到3次
const reg = /(ab){2,3}/;
// 可匹配：abab（2次）、ababab（3次）
// 不可匹配：ab（1次）、abababab（4次）
```

## 捕获组

捕获组是分组的延伸，作用是将匹配到的内容（尤其是分组内的内容）保存下来，方便后续提取或替换，核心用法如下：

### 捕获组的匹配与提取

用`()`定义捕获组后，匹配成功时，会将整体匹配内容和每个分组的内容依次保存到返回数组中。

```javascript
const str = "2026-03-15";
// 定义3个捕获组，分别匹配年、月、日
const reg = /(\d{4})-(\d{2})-(\d{2})/;
const result = str.match(reg);
console.log(result);
// 结果：["2026-03-15", "2026", "03", "15"]
```

结果说明：

- result[0]：整体匹配的内容（完整日期字符串）。

- result[1]：第一个捕获组匹配的内容（年：2026）。

- result[2]：第二个捕获组匹配的内容（月：03）。

- result[3]：第三个捕获组匹配的内容（日：15）。

### 捕获组在replace()中的使用

替换时，可通过`$n`（n为捕获组序号，从1开始）引用对应的捕获组内容，实现灵活替换。

```javascript
const str = "2026-03-15";
// 用捕获组替换日期格式（年-月-日 → 月/日/年）
const result = str.replace(/(\d{4})-(\d{2})-(\d{2})/, "$2/$3/$1");
console.log(result); // 03/15/2026
```

## 非捕获组

非捕获组的作用是“分组但不保存匹配结果”，适用于只需要组合规则、不需要提取分组内容的场景，语法为`(?:...)`。

```javascript
// 非捕获组：只匹配"abc"整体2次，不保存分组结果
const reg = /(?:abc){2}/;
const str = "abcabc";
const result = str.match(reg);
console.log(result); // ["abcabc"]（无分组内容）
```

对比捕获组：若使用`(abc){2}`，匹配结果会包含分组内容`["abcabc", "abc"]`，非捕获组则不会保存分组信息，更节省内存。

## 常见修饰符

修饰符用于修改正则的匹配规则，放在正则表达式的末尾（字面量写法）或构造函数的第二个参数，核心常用修饰符共4种：

### 1. g （全局匹配）

含义：匹配字符串中所有符合规则的内容，而非只匹配第一个。

```javascript
const str = "a1b2c3";
// 全局匹配所有数字
console.log(str.match(/\d/g)); // ["1", "2", "3"]
// 不带g，只匹配第一个数字
console.log(str.match(/\d/)); // ["1"]
```

### 2. i （忽略大小写）

含义：匹配时忽略字母的大小写，不区分大写和小写。

```javascript
const reg = /abc/i;
// 可匹配：abc、ABC、Abc、aBc等
console.log(reg.test("ABC")); // true
```

### 3. m （多行匹配）

含义：让`^`和`$`不再只匹配整个字符串的开头和结尾，而是匹配每一行的开头和结尾。

```javascript
// 多行字符串（换行符分隔）
const str = `hello
world`;
// 不带m，^world匹配整个字符串开头，返回false
console.log(/^world/.test(str)); // false
// 带m，^world匹配第二行开头，返回true
console.log(/^world/m.test(str)); // true
```

### 4. s （dotAll修饰符）

含义：让`.`元字符可以匹配换行符`\n`（默认情况下`.`不能匹配换行符）。

```javascript
const str = "a\nb";
// 不带s，.不能匹配换行符，返回false
console.log(/a.b/.test(str)); // false
// 带s，.可以匹配换行符，返回true
console.log(/a.b/s.test(str)); // true
```

## 贪婪匹配和懒惰匹配

贪婪匹配和懒惰匹配是量词的两种匹配模式，默认情况下量词为贪婪匹配，核心区别在于“匹配时是否尽可能多匹配”：

### 1. 贪婪匹配（默认模式）

含义：量词会尽可能多地匹配符合规则的内容，直到无法匹配为止。

```javascript
const str = "<div>hello</div><p>world</p>";
// 贪婪匹配：尽可能匹配最长的内容（从<开始到最后一个>结束）
console.log(str.match(/<.*>/)); 
// 结果：["<div>hello</div><p>world</p>"]
```

### 2. 懒惰匹配（非贪婪匹配）

含义：在量词后面加`?`，让量词尽可能少地匹配符合规则的内容，匹配到第一个符合条件的内容就停止。

```javascript
const str = "<div>hello</div><p>world</p>";
// 懒惰匹配：尽可能匹配最短的内容，配合g匹配所有符合规则的内容
console.log(str.match(/<.*?>/g)); 
// 结果：["<div>", "</div>", "<p>", "</p>"]
```

### 常见懒惰量词

在对应的贪婪量词后面加`?`，即可变为懒惰量词：

# 面试高频考点

整理前端面试中高频考查的正则知识点，明确核心区别和考点：

## 1. test() 和 exec() 的区别

- test()：只关心是否匹配，返回布尔值（`true`/`false`），不返回匹配详情。

- exec()：返回匹配详情（数组），包含匹配内容、index、input，匹配失败返回`null`，可获取捕获组信息。

## 2. match() 和 matchAll() 的区别

- match()：常见且够用，带`g`时返回所有匹配项组成的数组，不带`g`时返回第一个匹配项及详情（含捕获组）。

- matchAll()：适合需要获取所有匹配项+每个匹配项的捕获组信息的场景，返回一个迭代器，需用`for...of`遍历。

```javascript
const str = "a1 b2 c3";
const reg = /([a-z])(\d)/g;
// matchAll() 获取所有匹配项及捕获组
for (const item of str.matchAll(reg)) {
  console.log(item);
  // 输出：["a1", "a", "1"], ["b2", "b", "2"], ["c3", "c", "3"]
}
```

## 3. 为什么有时候test()连续执行结果不一样

核心原因：当正则表达式带有`g`修饰符时，正则对象会记录一个`lastIndex`属性，标记上一次匹配的结束位置，下一次匹配会从`lastIndex`开始。

```javascript
const reg = /\d/g;
console.log(reg.test("1")); // true（匹配成功，lastIndex变为1）
console.log(reg.test("1")); // false（从index=1开始，无匹配内容，lastIndex重置为0）
console.log(reg.test("1")); // true（从index=0开始，再次匹配成功）
```

### 解决办法

- 不需要全局匹配时，不要给test()对应的正则加`g`修饰符。

- 必须加`g`时，每次执行test()前，手动重置`reg.lastIndex = 0`。

## 4. 贪婪和非贪婪的区别

- 贪婪匹配（默认）：量词尽可能多匹配符合规则的内容，直到无法匹配。

- 非贪婪匹配（加`?`）：量词尽可能少匹配符合规则的内容，匹配到第一个符合条件的就停止。

# 什么叫“字符之间的位置”

看这个字符串：

```JavaScript

abc
```

它其实不只是 3 个字符，你也可以把它看成有 4 个位置：

```JavaScript

|a|b|c|
```

注意这些竖线 `|` 不是字符串内容，
 只是为了帮助你理解：

- 第一个 `|`：`a` 前面的位置

- 第二个 `|`：`a` 和 `b` 中间的位置

- 第三个 `|`：`b` 和 `c` 中间的位置

- 第四个 `|`：`c` 后面的位置

所以：

> **字符串里不仅有字符，也有字符之间的位置。**
> 
> 

正则里的某些语法，就是专门用来匹配这些“位置”的。
