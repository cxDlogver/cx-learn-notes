#### 【数组判断】

`Object.prototype.toString.call(obj)`

`toString()`返回当前对象的**类型字符串**表示，使用 call 是为了设置 this 指向 value，这样你可以对任意数据类型调用它。

```js
"[object Type]"
```

#### 【类数组】

定义链接字符串函数

```js
function myConcat(separa) {
  var args = Array.prototype.slice.call(arguments, 1);
  return args.join(separa);
}
myConcat(", ", "red", "orange", "blue");
// "red, orange, blue"
myConcat("; ", "elephant", "lion", "snake");
// "elephant; lion; snake"
myConcat(". ", "one", "two", "three", "four", "five");
// "one. two. three. four. five"
```

这段代码体现了JS对象利用对象原型调用方法的方式。

```js
Array.prototype.slice.call(array, 1)
==> array.slice(1) ==> array.slice.call(array, 1)
```

为什么不用 `arguments.slice(1)`。

因为：

- `arguments` 是一个类数组对象，但它 **不是真正的数组**
- 它没有 `.slice()` 方法
- 所以需要用 `Array.prototype.slice.call()` 来“借用”数组的方法

但是有另一种方式：

```js
[...arguments].slice(1)
```

### JSON

#### 一、什么是 JSON？

**JSON**（JavaScript Object Notation）是一种轻量级的数据交换格式。它使用**键值对**和**有序数组**来表示数据，语法上和 JavaScript 对象结构类似，但它是一种**纯文本格式**，不依赖任何编程语言。

JSON 广泛用于前后端之间的数据传输，因为它易于阅读、编写和解析，并且几乎被所有现代语言所支持（如 JavaScript、Python、Java、Go 等）。

------

#### 二、JSON 的特点

1. **轻量级**
    JSON 是纯文本格式，结构紧凑，传输开销小，适合在网络中快速传输。
2. **结构清晰**
    数据以键值对和数组形式表达，层次分明，便于理解和维护。
3. **语言无关性**
    虽然起源于 JavaScript，但它是一种独立的格式，几乎所有主流语言都内置支持 JSON 的读写。
4. **易于解析和生成**
    在 JavaScript 中可以使用 `JSON.parse()` 和 `JSON.stringify()` 轻松进行 JSON 和对象的互相转换；在其他语言中也有类似的函数库。
5. **数据类型有限**
    JSON 支持的数据类型包括：字符串、数字、布尔值、数组、对象和 null，不支持函数、日期、undefined、正则等复杂结构。

------

#### 三、JSON 的作用

1. **前后端数据传输（最核心用途）**

JSON 是 Web 中最常用的数据交换格式。例如浏览器通过 Ajax 或 fetch 请求服务器时，请求和响应的数据几乎都是 JSON 格式。这是因为 JSON 格式小、解析快，适合频繁交互。

2. **配置文件格式**

JSON 常用于保存系统或项目的配置信息，例如 Node.js 中的 `package.json` 就是一个典型的配置文件。

3. **本地数据存储**

在浏览器中可以将 JSON 字符串存入 localStorage 或 sessionStorage，用于持久化保存用户状态或缓存数据。

4. **跨平台数据交换**

JSON 是 API 接口返回数据的标准格式，尤其在 RESTful 接口中，JSON 格式的通用性和可读性使其成为行业标准。

------

#### 四、为什么 JSON 能实现这些作用？

- **轻量和结构化的格式**：相比于 XML，JSON 更简洁，传输效率高，降低了前后端交互的负担。
- **易于程序解析**：JSON 不仅可读性强，也易于机器快速解析，使其非常适合作为接口响应格式。
- **跨语言支持强**：由于 JSON 是纯文本格式，任何语言只要能解析字符串就能处理 JSON，因此在系统集成或跨语言通信中非常受欢迎。
- **兼容 JavaScript**：浏览器原生支持 JSON，可以直接操作，提升了开发效率。

> 在请求和响应过程中，传输的是 **JSON 字符串**，因为网络传输只能处理文本数据。前端在发送前会使用 `JSON.stringify()` 将对象转为字符串，后端返回的数据也通常是 JSON 字符串，前端再通过 `JSON.parse()` 转为对象使用。
>
> 不过现代框架中如axios会自动完成解析。

### 类型转换

#### 【`in`类型转换】

```js
'1' in {1: ''}    // true
 1 in {1: 'a'}    // true
 1 in ['a', 'b']  // true
```

**1. `'1' in {1: ''} // true`**

- 在 JavaScript 中，对象的键 **会被自动转换成字符串**。
- `{1: ''}` 实际等同于 `{'1': ''}`。
- `'1' in {1: ''}` 就是在检查对象是否有键 `"1"`，结果是 **true**。

------

**2. `1 in {1: 'a'} // true`**

- 当用数字作为 `in` 左操作数时，JavaScript 会**自动把它转换为字符串**。
- 所以 `1 in {1: 'a'}` 等价于 `'1' in { '1': 'a' }`。
- 对象确实有这个键 → **true**。

------

**3. `1 in ['a', 'b'] // true`**

- 数组在底层也是对象，键是**索引号的字符串形式**：

  ```
  js
  
  
  复制编辑
  ['a', 'b'] 相当于 { '0': 'a', '1': 'b', length: 2 }
  ```

- `1 in ['a', 'b']` 检查的是数组是否有**索引 1**这个属性 → 有，结果是 **true**。

------

**📌 总结：`in` 运算符的规则**

1. **左边**：属性名（会被转成字符串）
2. **右边**：对象或数组
3. 作用：判断左边的属性名是否存在于右边对象（包括继承链上的属性）

#### 【布尔转换】

```js
[0, "", " ", null, undefined, NaN].map(Boolean); 
// 输出结果：[false, false, true, false, false, false]
```

`Boolean`本身是一个构造函数，这里传入`Boolean`作为参数，相当于传入一个`function Boolean(value){}`函数。 

#### 【对象类型转换】

对象的类型转换有三个方向：

- **转字符串**：`String(obj)`、`'abc' + obj`
- **转数字**：`Number(obj)`、算术运算（`+` 除了字符串拼接）
- **转布尔值**：`Boolean(obj)`（对象永远是 `true`，不需要复杂步骤）

------

**核心算法：ToPrimitive**

JavaScript 规范（ECMAScript）里定义了一个 **`ToPrimitive` 抽象操作**：

1. 如果对象有 `[Symbol.toPrimitive]` 方法 → 调用它

   ```js
   let obj = {
     [Symbol.toPrimitive](hint) {
       return hint === 'string' ? 'text' : 123;
     }
   };
   String(obj) // 'text'
   Number(obj) // 123
   ```

2. **否则**根据 **hint**（提示类型）选择调用顺序：

   - 如果 hint 是 `"string"` → 先 `toString()`，再 `valueOf()`
   - 如果 hint 是 `"number"` 或 `"default"` → 先 `valueOf()`，再 `toString()`

------

**内置方法的作用**

- **`valueOf()`**：返回对象的**原始值**（默认大多数对象返回自身，所以一般没用）
- **`toString()`**：返回对象的字符串表示（数组会变成 `"1,2,3"`）

举例：

```js
let obj = { value: 42 };

obj.toString = function() { return 'Hello'; };
obj.valueOf = function() { return 42; };

String(obj) // "Hello"   (string hint → toString 优先)
Number(obj) // 42        (number hint → valueOf 优先)
```

------

**特殊情况**

- 对象转布尔值：任何对象（包括空对象、空数组）都是 `true`

  ```js
  Boolean({}) // true
  Boolean([]) // true
  ```

- 数组转字符串：`[].toString()` → `""`，`[1,2,3].toString()` → `"1,2,3"`

- `Date` 对象默认 hint 是 `"string"`，跟其他对象不同

### 原型

#### 【`Object.defineProperty`】

向原型中添加新的属性方法**** 

```js
let obj = {};

Object.defineProperty(obj, 'method', {
  value: function () {
    console.log('Hello');
  },
  writable: true,      // 是否允许修改 value
  enumerable: true,    // 是否允许被枚举（出现在 for...in、Object.keys）
  configurable: true   // 是否允许删除或重新定义
});

obj.method(); // Hello
```

 **重要参数说明**

`Object.defineProperty` 第三个参数是 **属性描述符对象**，常用配置有：

| 配置项         | 类型     | 作用                    |
| -------------- | -------- | ----------------------- |
| `value`        | 任意类型 | 属性的值                |
| `writable`     | 布尔值   | 是否可修改 `value`      |
| `enumerable`   | 布尔值   | 是否可枚举              |
| `configurable` | 布尔值   | 是否可删除或重新配置    |
| `get`          | 函数     | 访问属性时执行的 getter |
| `set`          | 函数     | 设置属性时执行的 setter |

> **注意**：`value` 和 `get/set` 不能同时使用。

**和直接赋值的区别**

```
obj.method = function () { ... };
```

这种方式默认：

- `writable: true`
- `enumerable: true`
- `configurable: true`

而 `Object.defineProperty` **可以精确控制**这些特性。
