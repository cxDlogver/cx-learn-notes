# 在原字段中返回脱敏状态和字段标识

头达数据分散在多个业务接口中，字段同时包含字符串和数值类型。最终约定由服务端在返回前改写受控字段：保留原字段类型，将固定前缀和字段标识或状态标记合并为一个 `value`。前端组件只需传递 `value`，不需要再单独透传字段标识。

## 备选方案

- 固定前缀与字段标识合并：`value = "****<front_key>"`。采用此方案，脱敏值和字段标识在组件传递过程中始终保持在一起。
- `value` 与字段标识分开：`value = "****"`，`front_key = "<front_key>"`。不采用，所有中间组件都要同时传递两个字段，容易漏传或对应错误。

## 影响

新增受控字段时，需要同步配置字段标识和权限映射。前后端共同维护脱敏前缀和保留状态标记；服务端不能返回缺少字段标识或状态标记的占位值，前端负责从 `value` 中解析对应状态。
