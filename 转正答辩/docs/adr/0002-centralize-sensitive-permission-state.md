# 前端敏感权限采用公共状态和页面适配

受控数据分布在列表、详情和多个业务模块中。前端统一处理协议解析、权限状态和公共操作，字段与模块分别使用适合自己的展示方式；页面只保留作者信息、协作流程、数据查询和刷新方式。这样可以避免各页面重复实现权限判断，也不会让公共组件依赖具体业务。

## 备选方案

- 每个页面分别处理权限：改动直接，但相同状态容易出现不同交互，一、二期也会重复修改。
- 公共状态加页面适配：采用此方案。公共部分统一规则，页面保留必要差异。

## 影响

新增受控字段时优先接入公共渲染入口，特殊字段和模块再单独适配。配置缺失或权限请求失败时保持脱敏，不能由页面自行放开。
